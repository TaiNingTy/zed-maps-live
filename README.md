# Zed Maps: the live map

The running copy of the Zed Maps prototype: station, street and building as one route, walkable in 3D.

**Open it:** https://tainingty.github.io/zed-maps-live/

Films and an introduction: https://github.com/TaiNingTy/zed-maps-demo · Project notes: https://www.addon.work/project/zed-maps

## Status

Prototype, in active development. This repository holds only what a browser needs to run the page; it is published
so the map can be opened, not as a library.
